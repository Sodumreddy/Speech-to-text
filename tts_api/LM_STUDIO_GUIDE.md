# Using LM Studio with Llama 3.2 for Real-time Transcription Insights

This guide explains how to set up and use LM Studio to provide real-time AI insights during transcription.

## Prerequisites

1. Install [LM Studio](https://lmstudio.ai/) on your computer.
2. Ensure all requirements are installed:
   ```bash
   pip install -r requirements.txt
   ```

## Setting Up LM Studio

1. Open LM Studio application.
2. Download Llama 3 (8B or 70B model depending on your hardware capabilities).
3. In the "Local Inference Server" tab, select the Llama 3 model.
4. Start the server by clicking "Start Server". 
5. Make sure the server is running on http://localhost:1234 (default port).
6. Ensure "OpenAI compatible server mode" is selected.

## Configuration

1. Make sure your `.env` file contains the LM Studio settings:
   ```
   LM_STUDIO_BASE_URL=http://localhost:1234/v1
   LM_STUDIO_MODEL=llama3
   ```

2. The model name should match what you're using in LM Studio.

## Running the Application

1. Start MongoDB:
   ```bash
   mongod
   ```

2. Start the FastAPI application:
   ```bash
   python run.py
   ```

3. Start ngrok to expose your application:
   ```bash
   python start_ngrok.py
   ```

4. Configure Twilio to use your ngrok URL + "/voice" as the webhook for calls.

## Testing the Integration

1. Open your application in the browser:
   - Local: http://localhost:8000/static/index.html
   - Public: https://[your-ngrok-url]/static/index.html

2. Make a call to your Twilio number.

3. You should see:
   - Live transcription appearing in the "Live Transcription" tab
   - AI insights being generated in the "AI Insights" section
   - The ability to ask questions about the conversation

## Troubleshooting

1. **LM Studio Server Not Responding**:
   - Check the LM Studio logs in the application
   - Ensure the server is running and port 1234 is accessible
   - Test the API with a curl command:
     ```bash
     curl -X POST http://localhost:1234/v1/chat/completions \
       -H "Content-Type: application/json" \
       -d '{"model":"llama3","messages":[{"role":"user","content":"Hello!"}]}'
     ```

2. **No Insights Generated**:
   - Check the application logs for errors
   - Ensure you have enough text in the transcription (at least 50 characters)
   - Verify LM Studio is properly configured

3. **Slow Response Time**:
   - Llama models can be resource-intensive
   - Consider using a smaller model or reducing the `max_tokens` parameter in `llm_rag.py`
   - Ensure your computer has sufficient resources (GPU recommended)

## Customizing Insights

You can customize how insights are generated by modifying the prompts in `llm_rag.py`. For example:

- To change the system prompt, edit the `system_prompt` variable in the `answer_from_live_transcription` method.
- To adjust how frequently insights are generated, modify the `insight_interval` variable in the WebSocket handler.

Remember that more frequent insights will increase the load on your system.
